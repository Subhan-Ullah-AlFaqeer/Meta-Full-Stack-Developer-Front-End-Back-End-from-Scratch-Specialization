# ⚛️ Course 6: Advanced React

Welcome to **Course 6** of the **Meta Front-End Developer** (and **Meta Full-Stack Developer**) Professional Certificate program! This course elevates your front-end engineering expertise by diving into advanced React concepts, complex component patterns, global state management, remote API integration, custom hook creation, and automated component testing. You will master efficient list rendering, controlled forms, React Context, `useEffect` and `useReducer` hooks, Higher-Order Components (HOCs), Render Props, and robust testing using Jest and React Testing Library (RTL).

---

## 📝 Core Technical Objectives
- **Advanced Components & Forms:** Efficiently rendering arrays with unique keys, building controlled form components, and lifting shared state up to common ancestors.
- **Global State & Side Effects:** Leveraging React Context for global state and utilizing `useEffect`, `useReducer`, and `useRef` to handle side effects and asynchronous remote API data fetching.
- **Custom Hooks & Advanced Patterns:** Authoring custom hooks to extract reusable stateful logic, embracing component composition, and encapsulating behavior via HOCs and Render Props.
- **Automated Testing & Capstone Delivery:** Writing comprehensive unit and integration test suites using Jest and RTL, alongside building and deploying a professional React portfolio capstone.
