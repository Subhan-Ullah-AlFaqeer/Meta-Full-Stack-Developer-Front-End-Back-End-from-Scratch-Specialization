# 🌐 Course 9, Module 1: Introduction to Django

Welcome to **Module 1** of **Django Web Framework** (Course 9 of the Meta Full-Stack Developer Specialization)! This introductory module explores server-side web development principles, Django's core purpose, project and application structures, the Model-View-Template (MVT) architectural pattern, the DRY (Don't Repeat Yourself) principle, and essential command-line tools like `django-admin` and `manage.py`.

---

## 📝 Core Technical Objectives
- **DRY Principle & MVT Architecture:** Applying the "Don't Repeat Yourself" coding standard and leveraging the Model-View-Template pattern to guarantee code reusability.
- **Projects vs. Applications:** Differentiating between a Django project container and individual modular apps, and setting up correct internal directory structures.
- **Command-Line Tooling:** Using `django-admin` to scaffold projects and `manage.py` to handle runtime environments, server execution, and administrative tasks.
- **Development Environment Setup:** Configuring virtual environments, integrating VS Code, and verifying web development prerequisites.
