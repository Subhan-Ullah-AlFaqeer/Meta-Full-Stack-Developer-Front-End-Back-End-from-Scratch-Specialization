# 🌐 Course 9: Django Web Framework

Welcome to **Course 9** of the **Meta Full-Stack Developer** Professional Certificate program! In this course, you leverage the Django web framework to build, secure, and administer a production-ready web server. You will explore project scaffolding, Model-View-Template (MVT) architecture, URL routing, view logic, model creation and migrations, Object-Relational Mapping (ORM), Django forms, template language (DTL) rendering, admin permission management, MySQL integration, and the "Little Lemon" capstone project.

---

## 📝 Core Technical Objectives
- **Full-Stack Web Architecture:** Designing complete Django web applications utilizing Python, HTML, CSS, and the Model-View-Template (MVT) design pattern.
- **Request-Response Cycle:** Implementing views, routes, parameters, and URL configurations to handle incoming HTTP traffic seamlessly.
- **Data Modeling & Forms:** Building database tables through Django models, executing migrations, and generating dynamic web forms and ModelForms.
- **Template Engine & UI:** Leveraging the Django Template Language (DTL), template inheritance, and context mapping to display persistent database records dynamically.
- **Administration & Best Practices:** Securing applications, managing user permissions via the built-in Django Admin panel, and testing/deploying web apps.

## 💡 Visual Pipeline Reference

The comprehensive end-to-end Django full-stack web application request, routing, MVT processing, and database persistence pipeline governing Course 9:

- **End-to-End Django Full-Stack Application Pipeline**:

$$\begin{aligned} \text{HTTP Request: } &\text{URL Routing (urls.py)} \xrightarrow{\text{Views (views.py)}} \text{Business Logic and Form Validation} \\ \text{MVT Data and UI: } &\text{Django ORM / MySQL DB} \xleftrightarrow{\text{Models (models.py)}} \text{Views} \xrightarrow{\text{DTL Engine}} \text{Rendered HTML UI Response} \\ \text{Capstone: } &\text{Full Application Synthesis} \xrightarrow{\text{Little Lemon Website}} \text{Transition to Web APIs and REST} \end{aligned}$$
