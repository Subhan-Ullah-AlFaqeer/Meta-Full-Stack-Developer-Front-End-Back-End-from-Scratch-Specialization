# ⚛️ Course 5, Module 1: React Components

Welcome to **Module 1** of **React Basics** (Course 5 of the Meta Front-End / Full-Stack Developer Specialization)! This foundational module introduces you to the React.js library and component-based architecture for building dynamic Single-Page Applications (SPAs). You will learn how to write JavaScript modules (imports/exports), create reusable functional components, pass and manipulate `props` and children, write and style JSX syntax, use arrow functions and ternary operators, and render multiple interactive components.

---

## 📝 Core Technical Objectives
- **React Architecture & SPAs:** Explaining the core concepts behind React, component-based design, and how Single-Page Applications function in the real world.
- **Components & Folder Structure:** Creating functional components, organizing component directories, and managing code reusability using JavaScript ES6 modules (`import`/`export`).
- **Props & Data Flow:** Passing data down component trees using `props`, handling children elements, and effecting visual updates dynamically.
- **JSX Syntax & Expressions:** Writing JavaScript XML (JSX), embedding expressions, utilizing arrow functions, and evaluating conditions with ternary operators.
