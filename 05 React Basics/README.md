# ⚛️ Course 5: React Basics

Welcome to **Course 5** of the **Meta Front-End Developer** (and **Meta Full-Stack Developer**) Professional Certificate program! This course introduces you to the fundamentals of React.js—the powerful JavaScript library created by Meta for building scalable, high-performance, and interactive user interfaces for web and mobile applications. You will learn component-based architecture, JSX templating, props data flow, event handling and state management via hooks, conditional rendering, single-page navigation, asset bundling, and capstone application development.

---

## 📝 Core Technical Objectives
- **Component-Based Architecture:** Building modular, reusable functional components to render dynamic views where data changes over time.
- **Props & Unidirectional Data Flow:** Passing configuration data, expressions, and children cleanly down component hierarchies.
- **State & Event Management:** Capturing user interactions through synthetic event listeners and managing local component state reactively using the `useState` hook.
- **Navigation, Assets & Capstone Build:** Setting up client-side routing, implementing conditional rendering, bundling static media assets, and building a fully functional React calculator application.
