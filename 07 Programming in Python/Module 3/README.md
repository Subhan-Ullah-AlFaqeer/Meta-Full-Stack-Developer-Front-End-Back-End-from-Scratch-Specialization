# 🐍 Course 7, Module 3: Programming Paradigms

Welcome to **Module 3** of **Programming in Python** (Course 7 of the Meta Front-End / Full-Stack Developer Specialization)! This module explores core programming paradigms in Python, transitioning from procedural programming and algorithmic thinking (including Big-O complexity) to functional programming concepts (pure functions, recursion, map/filter, and comprehensions) and comprehensive Object-Oriented Programming (OOP principles, classes, instantiation, inheritance, abstract classes, and Method Resolution Order).

---

## 📝 Core Technical Objectives
- **Procedural Programming & Algorithms:** Understanding procedural flow, writing step-by-step algorithms, and analyzing algorithmic complexity using Big-O notation.
- **Functional Programming Concepts:** Utilizing pure functions, recursion, built-in transformations (`map`, `filter`), and list/dictionary comprehensions.
- **Object-Oriented Programming (OOP):** Defining classes and instantiating objects, implementing instance methods, and applying core OOP principles (inheritance, multiple inheritance, and abstract classes).
- **Advanced OOP Mechanics:** Navigating Method Resolution Order (MRO) and designing robust class hierarchies in Python.
