# 💻 Course 2, Module 3: Programming Paradigms

Welcome to **Module 3** of **Programming with JavaScript** (Course 2 of the Meta Front-End / Full-Stack Developer Specialization)! This advanced module explores two major programming paradigms—functional programming and object-oriented programming (OOP)—along with modern ES6+ JavaScript features, DOM manipulation, event handling, and data exchange with JSON.

---

## 📝 Core Technical Objectives
- **Functional Programming (FP):** Understanding pure functions, first-class functions, recursion, and building modular functional programs.
- **Object-Oriented Programming (OOP):** Implementing classes, constructors, inheritance, default parameters, and applying core OOP principles (encapsulation, inheritance, polymorphism).
- **Scope & Variable Declarations:** Comparing scoping rules and hoisting behaviors across `var`, `let`, and `const`.
- **Modern ES6+ Features:** Utilizing template literals, destructuring assignment, `for...of` loops, and the spread (`...`) and rest (`...`) operators.
- **DOM Manipulation & JSON:** Selecting DOM elements, adding interactivity and event listeners, updating webpage content dynamically, and parsing/serializing JSON data.
