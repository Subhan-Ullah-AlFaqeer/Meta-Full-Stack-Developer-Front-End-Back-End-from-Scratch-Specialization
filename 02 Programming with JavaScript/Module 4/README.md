# 💻 Course 2, Module 4: Testing & Node.js

Welcome to **Module 4** (the final capstone module!) of **Programming with JavaScript** (Course 2 of the Meta Front-End / Full-Stack Developer Specialization)! This module introduces you to server-side JavaScript execution via Node.js, package management with npm (`package.json`), and professional software testing methodologies. You will explore the different types of testing, understand Test-Driven Development (TDD), and write your first automated unit tests using the Jest testing framework.

---

## 📝 Core Technical Objectives
- **Node.js & npm Ecosystem:** Understanding Node.js as a runtime environment, installing packages via npm, and managing dependencies and configuration using `package.json`.
- **Software Testing Fundamentals:** Explaining the importance of testing in software development and distinguishing between the three most prevalent testing types (Unit, Integration, End-to-End).
- **Test-Driven Development (TDD):** Adopting the TDD workflow of writing failing tests first, followed by implementation code to pass them.
- **Jest Unit Testing:** Writing, running, and verifying automated unit tests using the Jest framework to ensure code reliability and catch regressions.
