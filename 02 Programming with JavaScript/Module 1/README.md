# 💻 Course 2, Module 1: Introduction to JavaScript

Welcome to **Module 1** of **Programming with JavaScript** (Course 2 of the Meta Front-End / Full-Stack Developer Specialization)! This foundational module introduces you to the JavaScript programming language, its critical role in modern software and web development, and how to execute code inside the browser environment and VS Code. You will learn core programming fundamentals including variable declaration, primitive data types, common operators, conditional branching statements (`if`, `else`, `switch`), and looping constructs (`for`, `while`, nested loops).

---

## 📝 Core Technical Objectives
- **JavaScript Role & Ecosystem:** Explaining why JavaScript is indispensable for full-stack software development and interactive web applications.
- **Browser & Environment Setup:** Demonstrating how to write, execute, and test JavaScript code using browser consoles and Visual Studio Code.
- **Variables & Data Types:** Declaring variables (`let`, `const`, `var`), managing primitive data types (numbers, strings, booleans), and outputting values to the console.
- **Operators & Control Flow:** Utilizing arithmetic, assignment, logical, and comparison operators; mastering conditional statements; and implementing repetitive logic using `for` and `while` loops.
