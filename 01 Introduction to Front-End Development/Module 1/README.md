# 🌐 Course 1, Module 1: Get Started with Web Development

Welcome to **Module 1** of **Introduction to Front-End Development** (Course 1 of the Meta Front-End Developer / Meta Full-Stack Developer Specialization)! This foundational module introduces you to the web development landscape, distinguishing between front-end, back-end, and full-stack engineering roles. You will explore how the internet and web protocols (HTTP, TCP/IP) function, examine the core web technologies (HTML, CSS, JavaScript), learn how to use browser developer tools, and set up your local development environment using Visual Studio Code.

---

## 📝 Core Technical Objectives
- **Developer Roles & Specializations:** Differentiating the responsibilities of front-end, back-end, and full-stack developers, and understanding a typical day in the life of a front-end engineer.
- **Internet Infrastructure & Web Protocols:** Explaining how data moves across the internet, how web servers, browsers, and hosting work, and analyzing core internet protocols including HTTP and TCP/IP.
- **Core Web Technologies:** Introducing HTML (structure), CSS (styling), and JavaScript (interactivity), along with frameworks, libraries, and APIs.
- **Developer Environment & Tooling:** Inspecting web pages, editing content using browser developer tools, and configuring Visual Studio Code as your primary IDE.

## 🎯 Technical Skills Architecture

### 📊 Web Architecture & Protocol Literacy
- **Client-Server Dynamics:** Tracing how user requests travel through routers, DNS lookups, and internet protocols to retrieve web assets.
- **HTTP Method Understanding:** Differentiating between request types (GET, POST) and analyzing response headers and status codes.
- **DOM Inspection:** Using browser developer tools to inspect, evaluate, and dynamically test modifications to live web pages.

### 🤖 Applied Practice & Environment Setup
- **IDE Configuration:** Setting up Visual Studio Code on Coursera for local development and clean file management.
- **Command-Line Navigation:** Utilizing basic command-line interfaces to query network endpoints and manage project directories.
- **Capstone Project Awareness:** Gaining early exposure to the *Little Lemon* restaurant website capstone project that spans the specialization.
