# 🔌 Course 10, Module 1: REST APIs

Welcome to **Module 1** of **APIs** (Course 10 of the Meta Full-Stack Developer Specialization)! This foundational module introduces RESTful API development, exploring key characteristics and benefits, mapping CRUD operations to HTTP methods, understanding the request-response lifecycle, configuring local environments with `pipenv`, organizing a Django API project, applying clean REST naming conventions, distinguishing between authentication and authorization, and working with JSON and XML response formats.

---

## 📝 Core Technical Objectives
- **RESTful Principles & Characteristics:** Explaining the core constraints, benefits, and architectural design principles of RESTful APIs.
- **HTTP & CRUD Mapping:** Mapping standard CRUD operations to HTTP methods (`GET`, `POST`, `PUT`, `DELETE`) and interpreting status codes and response types.
- **API Routing & Naming:** Applying REST naming conventions and best practices to design clean, consistent, and predictable API routes.
- **Django API Project Setup:** Organizing a basic Django project environment using `pipenv`, VS Code, and essential API development tools.
- **Security, Auth & Formats:** Differentiating between authentication and authorization, enforcing access control, and handling JSON vs. XML response payloads.
