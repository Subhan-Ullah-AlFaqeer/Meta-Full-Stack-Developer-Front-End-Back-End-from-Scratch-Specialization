# 🗂️ Course 3, Module 2: Command Line

Welcome to **Module 2** of **Version Control** (Course 3 of the Meta Front-End / Full-Stack Developer Specialization)! This module equips you with essential command line interface (CLI) and Unix/Bash shell skills. You will learn how to navigate your hard drive, manage files and directories, execute text-processing utilities like `grep`, and combine commands using pipes (`|`) and redirection (`>`) to build powerful automation workflows.

---

## 📝 Core Technical Objectives
- **Command Line Fundamentals:** Understanding what the command line is, how it interacts with the operating system, and utilizing Bash terminals on macOS and Windows.
- **File System Navigation:** Traversing directory trees, checking current working directories (`pwd`), listing contents (`ls`), and changing directories (`cd`).
- **File & Directory Management:** Creating, moving, renaming, and deleting files and folders (`mkdir`, `touch`, `cp`, `mv`, `rm`) via Unix commands.
- **Pipes, Redirection & Text Processing:** Chaining commands using pipes, redirecting input/output streams, and searching text efficiently with `grep`.

## 🎯 Technical Skills Architecture

### 📊 Shell Operation & File Management
- **CLI Fluency:** Executing fast, text-based navigation and file operations without relying on graphical user interfaces.
- **Workflow Automation:** Combining multiple Unix utilities using pipes and redirection to process logs and text files efficiently.
- **Pattern Matching:** Using `grep` to search for specific strings and patterns across text files and project directories.

### 🤖 Applied Practice & Programming Labs
- **Directory Structuring:** Building clean, organized folder trees for software projects directly from the terminal.
- **Error Troubleshooting:** Managing file permission issues and path errors encountered during command execution.
- **Git Readiness:** Establishing the essential terminal proficiency required to execute Git version control commands in subsequent modules.
