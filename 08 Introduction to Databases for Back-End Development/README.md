# 🗄️ Course 8: Introduction to Databases for Back-End Development

Welcome to **Course 8** of the **Meta Full-Stack Developer** Professional Certificate program! Back-end developers build applications that allow users to store, search, extract, and manipulate data seamlessly. This course provides a comprehensive introduction to relational database management systems (RDBMS), MySQL syntax and commands, Structured Query Language (SQL) CRUD operations, data filtering/sorting, schema architecture, entity-relationship diagrams (ERDs), and normalization principles (1NF, 2NF, 3NF).

---

## 📝 Core Technical Objectives
- **Database Fundamentals & RDBMS:** Understanding how databases function, distinguishing between relational and non-relational management systems, and exploring alternative database technologies.
- **SQL CRUD Operations:** Executing MySQL syntax commands to create databases and tables, insert records, query data, and perform safe updates and deletions.
- **Data Filtering & Sorting:** Applying SQL operators, conditional `WHERE` clauses, sorting (`ORDER BY`), and distinct value extraction (`SELECT DISTINCT`).
- **Relational Design & Normalization:** Modeling database schemas using primary and foreign keys, drawing Entity-Relationship Diagrams (ERDs), and applying normalization standards (1NF, 2NF, 3NF).

## 🎯 Technical Skills Architecture
