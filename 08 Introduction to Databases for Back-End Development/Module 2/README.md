# 🗄️ Course 8, Module 2: Create, Read, Update and Delete (CRUD) Operations

Welcome to **Module 2** of **Introduction to Databases for Back-End Development** (Course 8 of the Meta Full-Stack Developer Specialization)! This module explores fundamental SQL data types (numeric, string, default values) and core database CRUD operations—learning how to create and drop databases/tables (`CREATE`, `DROP`, `ALTER`), insert records (`INSERT`), query data (`SELECT`), modify existing rows (`UPDATE`), and remove records (`DELETE`).

---

## 📝 Core Technical Objectives
- **SQL Data Types:** Differentiating between numeric data, string data, and configuring default values for column definitions.
- **Create & Read Operations (`CREATE`, `INSERT`, `SELECT`):** Creating databases and tables, altering table schemas, inserting new records, and retrieving data using SQL `SELECT` statements.
- **Update & Delete Operations (`UPDATE`, `DELETE`, `DROP`):** Modifying existing database records and securely deleting or purging obsolete rows and tables.
- **Practical CRUD Labs:** Executing hands-on database exercises to manage data workflows from scratch.

## 🎯 Technical Skills Architecture

### 📊 Relational Database Management Proficiency
- **Schema Engineering:** Defining precise data types and constraints to maintain database integrity and optimize storage.
- **CRUD Execution:** Writing clean, efficient SQL statements to create, read, update, and delete relational data records.
- **Querying Competency:** Utilizing `SELECT` statements to extract and filter exact subsets of data from tables.

### 🤖 Applied Practice & Labs
- **Table Creation Labs:** Successfully scaffolding relational tables, setting primary keys, and inserting structured datasets.
- **Record Maintenance:** Updating field values and deleting target records safely using conditional `WHERE` clauses.
- **Specialization Progression:** Establishing core CRUD competencies, fully prepared to advance into filtering, sorting, and advanced SQL operators.
